# План развития проекта (Roadmap): Zvuk LMS Plugin

## Stage 4: FLAC Lossless & DRM
- **Исследование**: Проверить возможность получения прямых ссылок на FLAC (без DRM).
- **ffmpeg Integration**: Если `flacdrm` зашифрован, реализовать расшифровку через `ffmpeg` в `ProtocolHandler`. Потребуется изучение алгоритма получения ключей (KMS).
- **Bitrate**: Добавить отображение реального битрейта в метаданных при воспроизведении.

## Stage 5+: Улучшение "Волны"
- **Бесконечный поток**: Реализовать механизм автоматического пополнения плейлиста новыми треками из Волны при достижении конца очереди.
- **Интерактив**: Добавить поддержку кнопок "Like" / "Dislike" в контекстное меню трека (через GraphQL мутации `addLike`, `removeLike`).
- **Пресеты**: Добавить выбор подтипов Волны (по настроению, по жанру), если API предоставляет такие возможности.

## Stage 6: Глубокая интеграция (Online Library)
- **Импортер**: Реализовать `Importer.pm` для синхронизации "Моей музыки" с локальной базой данных LMS. Это позволит трекам из Zvuk появляться в общих списках "Albums", "Artists" сервера.
- **Library Icons**: Отображение логотипа Zvuk на обложках альбомов в общем списке (через `addLibraryIconProvider`).

## Stage 7: Метаданные и Инфо-панели
- **ArtistInfo / AlbumInfo**: Интеграция с меню "Дополнительная информация". Показ биографий артистов и рецензий на альбомы, если они есть в Zvuk.
- **Lyrics**: Отображение текстов песен во время воспроизведения (поле `lyrics` в API).

## Технический долг
- **Кэширование**: Переход на более агрессивное кэширование метаданных артистов и альбомов для снижения нагрузки на API.
- **Тесты**: Создание набора юнит-тестов для API-клиента на Perl.
