# Руководство разработчика: Zvuk LMS Plugin

## 1. Структура файлов
- `Plugin.pm`: Точка входа. Управляет меню и жизненным циклом. Наследует `Slim::Plugin::OPMLBased`.
- `API/Async.pm`: Общение с сервером. Все запросы GraphQL должны проходить здесь. 
- `API.pm`: Общие хелперы и константы. Если нужно добавить новый URL или заголовок — это здесь.
- `ProtocolHandler.pm`: Логика проигрывания. Метод `getNextTrack` — самый важный.
- `Settings.pm` + `HTML/...`: Управление настройками в WebUI.

## 2. Работа с API Zvuk (GraphQL)
Все запросы идут на эндпоинт `https://zvuk.com/api/v1/graphql` методом **POST**.
Для отладки новых запросов используйте:
1. Браузер (Zvuk.com) -> DevTools -> Network -> Фильтр по `graphql`.
2. Копируйте как cURL и анализируйте `operationName` и `variables`.

**Важно**: В Perl-клиенте (`Async.pm`) используйте JSON-объекты для переменных. Всегда проверяйте соответствие типов (ID, Int, String).

## 3. Отладка
Для просмотра логов плагина используйте команду:
```bash
tail -f /var/log/squeezeboxserver/server.log | grep zvuk
```
В `Plugin.pm` и `Async.pm` включено логирование. Чтобы увидеть тела запросов и ответов, в настройках LMS (Settings -> Advanced -> Logging) установите уровень `DEBUG` для категории `plugin.zvuk`.

## 4. Зависимости
- **JSON::XS**: Используется для парсинга ответов.
- **Lyrion Music Server (LMS)**: Рекомендуемая версия 8.0+.

## 5. Полезные советы
- **Иконки**: Если иконка не отображается, проверьте права доступа к файлам в `html/images/` и соответствие регистра в пути.
- **Токен**: Токен Zvuk живет долго (до 1 года), но если API возвращает 401/403, первым делом проверьте валидность токена в браузере.
