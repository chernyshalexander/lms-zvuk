# Текущее состояние проекта: Zvuk LMS Plugin

## 1. Обзор проекта
Плагин предназначен для интеграции музыкального сервиса **Zvuk (zvuk.com)** в экосистему **Lyrion Music Server (LMS)**. 
На текущий момент реализован базовый функционал для прослушивания музыки, навигации по коллекции и поиска.

## 2. Реализованный функционал
- **Авторизация**: Поддержка нескольких аккаунтов через ввод `x-auth-token` (извлекается из кук браузера).
- **Навигация (Browse)**:
    - Глобальный поиск (Треки, Артисты, Альбомы, Плейлисты).
    - Раздел "Моя музыка" (Любимые треки, Плейлисты пользователя).
    - Переход (drill-down) к альбомам, топ-трекам артистов и содержимому плейлистов.
    - Поддержка пагинации (бесконечная прокрутка через `endCursor`).
- **Персональная волна**: Получение потока рекомендаций на основе профиля пользователя.
- **Воспроизведение**: 
    - Поддержка протокола `zvuk://`.
    - Резолвинг прямых ссылок на MP3-потоки в реальном времени.
    - Выбор качества (Mid ~192kbps, High 320kbps).
- **Настройки**: Web-интерфейс для управления токенами и качеством звука.

## 3. Архитектура
- **`Plugin.pm`**: Основной цикл, регистрация в меню "My Apps", обработка навигации и кэширование API-клиентов.
- **`API/Async.pm`**: Асинхронный клиент GraphQL. Использует `Slim::Networking::SimpleAsyncHTTP`.
- **`ProtocolHandler.pm`**: Резолвер потоков. Превращает `zvuk://track_id` в HTTP URL.
- **`API.pm`**: Хелперы для работы с метаданными, изображениями и кэшем.
- **`Settings.pm`**: Обработка настроек и валидация токенов.

## 4. Технические особенности (WAF Bypass)
Для успешной работы с API Zvuk плагин эмулирует поведение десктопного приложения, передавая обязательные заголовки:
- `x-app-name`: `web-zvuk-service-desktop-app`
- `x-device-id`: Генерируется один раз (UUID) и сохраняется в настройках.
- `user-agent`: Актуальная строка Chrome/Linux.
- `origin` / `referer`: `https://zvuk.com`.

## 5. Текущие проблемы и нюансы
- **GraphQL 400**: Некоторые запросы чувствительны к именам переменных (например, `first` вместо `limit`). Последние правки направлены на унификацию.
- **DRM**: Поле `flacdrm` в API указывает на защищенные потоки, которые на данный момент не поддерживаются.
- **Логотип**: Пути к иконкам в LMS чувствительны к регистру (используется `plugins/Zvuk/...`).
